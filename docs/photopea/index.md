# Photopea

## Rogner une image à une forme

1. Importer l’image à rogner _(Calque 1)_
2. Créer la forme de rognage _(Calque 2)_ et la placer sur l’image
3. Dans la pile des calques, placer le _Calque 1_ au-dessus du _Calque 2_
4. Faire un clic droit sur le _Calque 1_ → sélectionner **« Masque d’écrêtage »**

## Ajouter un fond avec un calque de remplissage

1. Importer l’image avec un fond transparent
2. Dans le menu, sélectionner Calque → Nouveau calque de remplissage → Incrustation couleur
3. Choisir la couleur souhaitée, puis valider
4. Dans la pile des calques, placer le calque de remplissage sous le calque de l’image
